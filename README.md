# 🚀 01..50projects50days

My **50 projects in 50 days** challenge: building HTML, CSS & JavaScript projects every day to level up my frontend skills 💻🔥

## 🎯 Goal

- ✅ Build 50+ mini web projects with HTML, CSS & JavaScript
- ✅ Finish in 25 days (about 2 projects per day)
- ✅ Learn in public and track progress daily
