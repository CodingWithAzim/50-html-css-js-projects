# 🚀 HTML-CSS-JS Projects

A collection of front-end projects built with **HTML, CSS and vanilla JavaScript** as part of the *50 Projects in 50 Days* challenge. Each project focuses on a specific concept such as layout, animation, DOM manipulation or user interaction.

🔗 **Live Demo:** https://codingwithazim.github.io/html-css-js-projects/

---

## 🎯 Purpose

- Strengthen core front-end fundamentals without frameworks
- Practice building small, complete, interactive UI components
- Maintain a public record of daily learning and progress

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Semantic structure |
| CSS3 | Flexbox, Grid, animations, responsive design |
| JavaScript (ES6+) | DOM manipulation, events, logic |
| GitHub Pages | Free hosting for live demos |

## 📁 Structure

```
html-css-js-projects/
├── index.html          # Home page listing all projects
├── _project_starter_/  # Reusable starter template
├── 01..xx../           # Individual projects
└── README.md
```

Each project folder contains its own `index.html`, `style.css` and `script.js`.

## ▶️ Run Locally

```bash
git clone https://github.com/CodingWithAzim/html-css-js-projects.git
cd html-css-js-projects
```

Open any project's `index.html` in your browser, or use the **Live Server** extension in VS Code.
